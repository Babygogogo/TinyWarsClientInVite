# Tiny Wars

A powerful Advance Wars fan-made clone.

Game: https://tinywars.online/

Discord: https://discord.gg/pTZdgJZnk

## Features
- Multi-player mode, including (ranked) matches and tourneys
- Single-player mode, including custom campaigns and war rooms
- Easy-to-use yet powerful sandbox and UI
- Editors for maps and custom campaigns
- Playable on any device with a browser installed

## Run / Build
1. install Node.js
1. download this repo
1. enter the repo and do npm install
1. then
    - to run: npm run dev
    - to build: npm run build
